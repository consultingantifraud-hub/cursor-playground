# 🚀 Настройка триггеров для системы контроля качества

## 📋 Необходимые триггеры

### 1. **AMO.gs - Синхронизация событий**
- **Функция**: `syncEventsToday()`
- **Тип**: Триггер по времени
- **Частота**: Каждые 5 минут
- **Описание**: Синхронизирует события звонков из amoCRM

### 2. **ИИ.gs - Транскрипция звонков**
- **Функция**: `chatToProTalkBot()`
- **Тип**: Триггер по времени
- **Частота**: Каждые 10 минут
- **Описание**: Обрабатывает звонки через ProTalk для получения транскрипции

### 3. **Оценка.gs - Оценка звонков**
- **Функция**: `ToProTalkBot()`
- **Тип**: Триггер по времени
- **Частота**: Каждые 15 минут
- **Описание**: Оценивает звонки через ProTalk на основе транскрипции

### 4. **Заметки.gs - Отправка в amoCRM**
- **Функция**: `sendNotesToAmoCRM()`
- **Тип**: Триггер по времени
- **Частота**: Каждые 30 минут
- **Описание**: Отправляет готовые транскрипции и оценки в amoCRM

## ⚙️ Как настроить триггеры

### Шаг 1: Открыть редактор триггеров
1. В Google Apps Script перейдите в **Триггеры** (левое меню)
2. Нажмите **+ Добавить триггер**

### Шаг 2: Настроить каждый триггер

#### Триггер 1: Синхронизация событий
```
Функция для запуска: syncEventsToday
Источник событий: Таймер
Тип таймера: Минутный таймер
Интервал: Каждые 5 минут
```

#### Триггер 2: Транскрипция
```
Функция для запуска: chatToProTalkBot
Источник событий: Таймер
Тип таймера: Минутный таймер
Интервал: Каждые 10 минут
```

#### Триггер 3: Оценка
```
Функция для запуска: ToProTalkBot
Источник событий: Таймер
Тип таймера: Минутный таймер
Интервал: Каждые 15 минут
```

#### Триггер 4: Отправка заметок
```
Функция для запуска: sendNotesToAmoCRM
Источник событий: Таймер
Тип таймера: Минутный таймер
Интервал: Каждые 30 минут
```

## 🔧 Дополнительные функции

### Ручной запуск
Для тестирования можно запускать функции вручную:
- `syncEventsToday()` - синхронизация
- `chatToProTalkBot()` - транскрипция
- `ToProTalkBot()` - оценка
- `sendNotesToAmoCRM()` - отправка

### Тестовые функции
- `testTranscription()` - тест транскрипции
- `testEvaluation()` - тест оценки
- `testSendNotes()` - тест отправки
- `checkProcessingStatus()` - проверка статуса
- `checkReadyToSend()` - проверка готовности

### Массовые операции
- `massExportCalls(days)` - массовая выгрузка звонков
- `quickExport()` - быстрая выгрузка за 24 часа
- `fullExport()` - полная выгрузка за 30 дней
- `sendAllReadyNotes()` - отправка всех готовых заметок

## 📊 Мониторинг работы

### Логи выполнения
- Все функции записывают детальные логи в консоль
- Ошибки логируются с пометкой `*** ОШИБКА`
- Успешные операции помечаются как `✅`

### Проверка статуса
Используйте функции проверки для мониторинга:
- `checkProcessingStatus()` - статус обработки
- `checkReadyToSend()` - готовность к отправке

## ⚠️ Важные замечания

1. **Порядок выполнения**: Сначала синхронизация, потом транскрипция, затем оценка, и наконец отправка
2. **Интервалы**: Не делайте интервалы слишком частыми, чтобы не перегружать API
3. **Ошибки**: При ошибках функции продолжают работу и записывают статус
4. **Лимиты API**: Учитывайте лимиты amoCRM и ProTalk API

## 🚨 Устранение неполадок

### Если триггеры не работают:
1. Проверьте права доступа к таблице
2. Убедитесь, что функции не содержат ошибок
3. Проверьте настройки в листе "БД"

### Если данные не обрабатываются:
1. Запустите `checkProcessingStatus()`
2. Проверьте заполненность колонок U, V, W, Y, Z, AA
3. Убедитесь в корректности настроек ProTalk и amoCRM
