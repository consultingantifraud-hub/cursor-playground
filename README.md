# amoCRM Integration Hub

Интеграционное решение для работы с amoCRM через Google Apps Script, включающее сбор событий, транскрипцию звонков и отправку заметок.

## 🚀 Быстрый старт

### 1. Настройка Google Sheets

1. Создайте новый Google Spreadsheet
2. Создайте лист "БД" с настройками:
   - `B2`: AMO_LONG_TERM_TOKEN (Bearer токен)
   - `B3`: AMO_SUBDOMAIN (например, 100detaley.amocrm.ru)
   - `B4`: SHEET_NAME (например, "АМО Звонки")
   - `B5`: BOT_TOKEN (токен ProTalk)
   - `B6`: BOT_ID (ID бота ProTalk)

### 2. Настройка колонок в целевом листе

Создайте лист с колонками:
- A: Время
- B: Ссылка на запись
- C: Сделка
- D: Воронка
- E: Статус
- F: ID сделки
- G: ID воронки
- H: ID статуса
- I: ID ответственного
- J: Ответственный
- K: Примечания + задачи
- L: Длительность
- M: Результат
- N: Тип
- O: ID звонка
- P: Все поля
- V: Транскрипция
- W: Оценка
- Z: Время отправки
- AA: Статус отправки

### 3. Установка скриптов

1. Откройте Google Apps Script (script.google.com)
2. Создайте новый проект
3. Скопируйте код из файлов в папке `src/` в соответствующие файлы .gs

## 🔧 Основные функции

### Сбор событий
- `syncEventsToday()` - синхронизация событий за последние 5 минут
- `syncEventsLastHours(hours)` - разовый сбор за N часов

### Транскрипция и оценка
- `ToProTalkBot()` - основной воркер транскрипции
- `qa_RunRowForce(row)` - принудительная обработка строки

### Отправка заметок
- `sendNotesToAmoCRM()` - отправка транскрипций и оценок в amoCRM

## ⚙️ Настройка

### Триггеры (опционально)
Настройте триггеры в Google Apps Script:
- `syncEventsToday` - каждые 5 минут
- `ToProTalkBot` - каждые 2 минуты
- `sendNotesToAmoCRM` - каждые 10 минут

### Конфигурация в листе "БД"

| Ячейка | Описание | Пример |
|--------|----------|--------|
| B2 | AMO токен | Bearer 12345... |
| B3 | Поддомен amoCRM | 100detaley.amocrm.ru |
| B4 | Имя целевого листа | АМО Звонки |
| B5 | ProTalk токен | pt_12345... |
| B6 | ProTalk bot ID | bot_67890... |
| H5 | Промпт для транскрипции | Транскрибируй звонок... |
| I5 | Промпт для оценки | Оцени качество звонка... |

## 🐛 Диагностика

### Проверка конфигурации
```javascript
II_selfcheck() // Проверка настроек
qa_Selftest()  // Тест ProTalk соединения
```

### Тестирование аудио
```javascript
qa_PingActiveRow()     // Пинг активной строки
qa_PingRow(123)        // Пинг строки 123
debugPingFirstAudioFromSheet_() // Пинг первого аудио
```

### Диагностика отправки заметок
```javascript
notes_DryRunWhyZero()  // Почему ничего не отправляется
```

## 📊 Мониторинг

- Логи транскрипции: лист "LOGS"
- Логи отправки заметок: лист "LOG_NOTES"
- Консоль Google Apps Script для отладки

## 🔒 Безопасность

- Токены хранятся в листе "БД"
- Используется синглтон для предотвращения параллельных запусков
- Валидация URL аудиофайлов
- Обработка ошибок и ретраи

3. Проверьте права доступа к amoCRM
4. Используйте диагностические функции
